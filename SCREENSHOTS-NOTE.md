# Screenshots Guide for Brainrot Bazaar

The images currently in `screenshots/` (`1-start.png`, `2-play.png`, `3-end.png`) are starter placeholders required for the validation pipeline to pass.

Before submitting this entry to the make.fun competition, you must replace them with **3 to 4 real in-game screenshots** captured directly while testing "Brainrot Bazaar" in Roblox Studio.

### Requirements for Screenshots:
1. **Aspect Ratio:** 16:9 (e.g., 1280x720, 1920x1080).
2. **File Size:** Each image must be strictly **<= 256 KiB** (compress if necessary using pngquant, tinypng, or jpeg).
3. **Naming & Order:**
   - `1-start.png`: Initial player spawn in the plaza showing the grand statue, spawn pad, and HUD. This first image by alphabetical name is the cover image and **MUST** also be uploaded as your Roblox experience's first thumbnail on the Creator Dashboard.
   - `2-play.png`: Active gameplay showing a brainrot character walking along the conveyor belt, buy prompt active, and player base.
   - `3-end.png` (or `3-hazard.png` / `3-base.png`): Displaying a claimed base with owned brainrots generating income, base lock barrier, or the Meme Storm hazard warning banner.
4. **Thumbnail & Icon:**
   - Upload the identical `1-start.png` image as your primary thumbnail on the Roblox Creator Dashboard (`Publish settings > Thumbnails`).
   - Upload an eye-catching icon for the experience on the Creator Dashboard (`Publish settings > Basic Info > Experience Icon`).
